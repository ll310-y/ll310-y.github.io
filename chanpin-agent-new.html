产品调研 Agent 框架

基于真空袋调研的方法论沉淀 · 从数据采集到产品落地方案 · 含产品画像发散

把一次具体的真空袋调研，抽象成一套可复用的产品调研方法论，最终交给 IT 开发成一个 Agent。

只聚焦产品端：人群、场景、任务、配置、外观、材质。不考虑利润、供应链可行性、认证成本。

一、Agent 总体架构

整个 Agent 分为 5 个模块，按顺序执行，每个模块都有明确的输入、处理逻辑和输出。

模块 名称 核心任务
M1数据采集从电商平台、评论、竞品页面获取结构化 + 非结构化数据
M2数据清洗把脏数据整理成可分析的规范表
M3用户任务挖掘从评论和搜索词中提炼用户任务地图
M4任务-配置匹配把用户任务映射到具体产品配置
M5产品落地方案生成输出可直接交付的产品定义文档

四、M3 用户任务挖掘

这一步要回答的核心问题：“用户到底雇这个产品去完成什么任务？”

不是问“产品卖得好不好”，而是问：谁在什么场景下用？要解决什么问题？最在意什么决策标准？

六、M5 产品落地方案生成
6.1 输出文档结构

每份产品落地方案必须包含以下 8 个部分：

  • 目标人群：主要人群画像、次要人群画像、人群规模判断（高/中/低）
  • 核心使用场景：主要场景、次要场景、场景优先级
  • 要解决的核心问题：用户任务、当前痛点（来自差评）、解决程度承诺
  • 产品具体配置：数量、尺寸组合（每个尺寸的数量）、材质（类型 + 厚度）、泵类型、密封方式、其他功能特性
  • 外观设计：配色方案、透明度设计（全透明/半透明/双面设计）、印刷设计、包装形式
  • 目标性能指标：密封持久性（承诺天数）、泵吸力（kPa）、泵续航（单次充电可抽袋数）、抗撕裂等级、可重复使用次数
  • 目标星级与差异化卖点：目标星级、核心卖点（3条以内）、差异化定位
  • 对标竞品：对标 ASIN、对标配置、我们的差异化点
七、Agent 的思考维度清单（给 AI 的提示词框架）

当 Agent 分析一个新品类的产品时，必须依次思考以下维度：

数据层

  • 这个品类的核心配置维度有哪些？
  • 哪些维度是用户最敏感的？
  • 哪些维度是市场同质化的？
  • 哪些维度存在差异化空间？

任务层

  • 用户买这个产品是为了完成什么任务？
  • 有几类不同的任务？优先级如何？
  • 每类任务的决策标准是什么？
  • 哪些任务已被满足？哪些存在缺口？

配置层

  • 每类任务对应的最优配置是什么？
  • 哪些配置组合在市场上是空白的？
  • 哪些配置组合销量最好但差评最多？
  • 哪些配置组合销量一般但好评率极高？

落地层

  • 最适合优先开发的配置是什么？
  • 这个配置对应的人群、场景、任务是什么？
  • 这个配置的外观、材质、性能细节是什么？
  • 这个配置和现有竞品的差异点是什么？

发散层（创意性发挥）

  • 这个品类有没有可以打破常规的创新方向？（交互、结构、体验）
  • 有没有跨界借鉴的可能？（其他行业的交互/结构/体验）
  • 有没有能引发社交媒体传播的创意点？
  • 有没有能满足情感需求而非功能需求的方案？

十、产品画像发散（创意性发挥）

以下方案不追求数据严格证明，仅做创意性发挥，目的是为新品开发提供打破常规的思考方向。

小篇幅阐述，每个方案包含：创意点、解决什么、目标人群、具体配置、外观、为什么值得试。

可视化压缩袋 · 压缩进度看得见

交互创新

创意点

核心创意袋身加入一条压缩进度指示条（类似温度计），当空气抽出到接近极限时，指示条从蓝色变为绿色，用户一眼就知道“抽好了”

解决什么

用户痛点当前用户最大的困惑是“不知道抽到什么程度才算好”，经常抽了半天还是不敢确定，或者过度抽气导致褶皱刺穿

目标人群

主要人群新手用户、追求确定性的人群、送礼场景（“一看就会用”）

具体配置

数量10个装 + 3种尺寸 + 无线泵
特殊设计袋身一侧印压缩进度条，配套泵上带指示灯

外观

配色透明袋身 + 蓝色封口 + 绿色进度条；泵为白色+蓝色呼吸灯
为什么值得试：这是一个“交互感”创新，成本不高（印刷+泵上小灯），但能形成强烈的视觉差异化，适合社交媒体传播。

模块化拼装压缩袋 · 像乐高一样自由组合

结构创新

创意点

核心创意袋子之间可以通过拉链拼接，用户可以把 2 个小袋拼成 1 个中袋，或者把 3 个中袋拼成 1 个大袋，自由组合

解决什么

用户痛点用户经常遇到“今天要装大衣，但只有小袋；明天要装被子，但只有大袋”的尺寸错配问题

目标人群

主要人群收纳需求多变、喜欢“一物多用”的年轻家庭、租房族

具体配置

数量6个基础袋（2小+2中+2大）+ 拼接拉链 + 无线泵；可拼成任意尺寸
特殊设计袋与袋之间的拼接拉链，支持 2-3 个袋子自由拼接

外观

配色透明袋身 + 蓝色封口 + 拼接处橙色拉链（视觉提示可拼接）
为什么值得试：打破了“一套固定尺寸”的行业惯例，形成“可成长”的产品概念，适合做品牌旗舰款。

香氛压缩袋 · 收纳也能有香气

体验创新

创意点

核心创意袋内加入可更换香氛片卡槽，用户放入香氛片后，压缩衣物时会留下淡淡清香，取出时衣物不闷、不潮、自带香气

解决什么

用户痛点用户反馈“长期存放后衣物有闷味/霉味”，尤其是地下室、床底存放场景

目标人群

主要人群女性用户、母婴家庭、有地下室/阁楼存放需求的家庭

具体配置

数量8个装 + 2种尺寸 + 无线泵 + 4片香氛片（薰衣草/柠檬/无香）
特殊设计袋内香氛片卡槽，用户可自行更换香氛片

外观

配色透明袋身 + 蓝色封口 + 香氛卡槽（淡紫色/淡黄色）
为什么值得试：从“功能性收纳”升级到“体验型收纳”，差异化极强，容易在社交媒体引发讨论。

三个发散方案对比

对比维度方案一（可视化）方案二（模块化）方案三（香氛）
创新类型交互创新结构创新体验创新
落地难度低中低
差异化强度中高高
传播潜力中高高

十一、这套框架的核心原则
  • 从用户任务出发，不从产品出发：先问“用户雇它干什么”，再问“该做什么产品”。
  • 数据是证据，不是答案：销量、评论、搜索词都是用户任务留下的痕迹。
  • 配置是任务的解，不是参数的堆：每个配置维度都要对应一个任务需求。
  • 外观是决策的一部分：配色、透明度、印刷都影响用户购买决策。
  • 可复用、可迭代：每次调研都是一次方法论的验证和优化。
  • 发散是创新的来源：不追求数据严格证明，为团队提供打破常规的思考方向。
